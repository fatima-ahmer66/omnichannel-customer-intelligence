# Dataset

This project uses an e-commerce sales transactions dataset obtained from Kaggle.

The dataset contains information about customer transactions, products, order dates, payment methods, regions, discounts, quantities, returns, and sales amounts.

## Data Preparation
The dataset was cleaned and prepared before analysis.

The preprocessing included:
- Handling missing values.
- Removing duplicate records.
- Standardizing categorical values.
- Converting columns into appropriate data types.
- Creating additional features for analysis.

## Dataset Source
Kaggle: https://www.kaggle.com/datasets/miadul/e-commerce-sales-transactions-dataset
