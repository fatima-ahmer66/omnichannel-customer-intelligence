# Project Visualizations

This folder contains the visual representations of the project's analytical results.

The visualizations include:

- Elbow Method plot.
- Silhouette Score plot.
- Customer Clustering visualization.
- Hierarchical Clustering Dendrogram.
- Class Distribution visualization.
- Confusion Matrix.
- ROC Curves.
- Association Rules visualization.

These graphs help explain customer behavior, model performance, and purchasing patterns.
